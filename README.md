# Omarchy Adventure Theme

Adventure and Adventure Time themes for [Omarchy](https://omarchy.org/), based on the palettes from [iTerm2 Color Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes).

## Install

```bash
omarchy-theme-install https://github.com/huacnlee/omarchy-adventure-theme
```

Or clone the repository and run:

```bash
./install.sh
```

Choose a variant:

```bash
omarchy theme set adventure
omarchy theme set adventure-time
```

## Variants

- **Adventure** — near-black, green, blue, and warm gold.
- **Adventure Time** — deep purple, green, indigo, and warm cream.
