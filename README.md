# Omarchy Adventure Theme

An Adventure theme for [Omarchy](https://omarchy.org/), based on the palette from [iTerm2 Color Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes).

## Install

```bash
omarchy theme install https://github.com/huacnlee/omarchy-adventure-theme
```

Or clone the repository and run:

```bash
./install.sh
```

The installer copies and activates the theme. Pick it up again later with:

```bash
omarchy theme set adventure
```
